# v2.4 docs and v3 migration / 旧版文档与迁移

**v2.4 users can continue using the structured workflow.** Starting with v3,
the npm product focuses on the local Web Workspace. The Plugin, Legacy CLI,
MCP, and Task Graph source remain available through separate entry points.

**给 v2.4 用户：** 项目从“同时提供 Web 与结构化协作的完整运行时”转向以
“本地 Web 双终端工作台”为主要产品入口。旧版文档和结构化路线仍可查阅；
请根据下面的版本入口选择指令，不要直接把旧命令中的版本换成 `latest`。

## What changed / 方向变化

| Area / 项目 | v2.4.0 | v3 Web-first / 新方向 |
| --- | --- | --- |
| Product entry / 产品入口 | Web and structured Plugin / CLI / MCP workflows documented together. / Web 与结构化工作流并列。 | Web Workspace is the main product entry. / 以 Web 工作台为主入口。 |
| npm distribution / npm 分发 | Complete standalone runtime, including structured commands. / 包含结构化命令的完整运行时。 | Web/help/version only, with required terminal/runtime modules. / 仅分发 Web 及必要运行时。 |
| Structured workflow / 结构化能力 | Agent Bus, durable Tasks, review evidence, MCP, Task Graphs. | Retained in the independently versioned GitHub Plugin and source Legacy runtime; npm CLI pins 2.4.0. / 通过 Plugin、源码 Legacy 或固定 npm 2.4.0 使用。 |
| Web cooperation / Web 协作 | Lightweight Web terminal collaboration already existed. / 已有轻量 Web 双终端。 | Continues as the main experience; new features depend on the selected source/release. / 成为主体验，新增功能以具体源码或发布版本为准。 |
| Task data / 任务数据 | Structured Task/Graph and Web task records are separate. / 结构化记录与 Web 任务分开。 | No automatic conversion of structured Tasks into Web tasks. / 不会把结构化 Task 自动转换为 Web 任务。 |

This is a product and distribution change, not removal of the structured source.
Plugin and npm Web version numbers are independent. This page does not declare
an end-of-support date for v2.4 or promise future updates.

这是产品重心与分发方式的变化，不代表删除旧版源码，也不代表承诺旧版维护期限。
v2.4 已有 Web 模式；v3 并非从零增加 Web。

## Continue with v2.4 or move to Web / 继续旧流程或使用新版

For the published structured CLI, keep the version explicit:

继续使用已发布的结构化 CLI 时，固定版本：

```sh
npx @hogancv/coordinate-agents@2.4.0 --help
npx @hogancv/coordinate-agents@2.4.0 doctor
```

The GitHub Plugin uses its own bundled runtime. From a current source checkout,
use `node bin/coordinate-agents-legacy.mjs` for structured commands. Current
source may include fixes beyond the historical release.

To use Web, follow [Getting started / 新版快速开始](./getting-started.html) and
[Workspace guide / 使用指南](./inspector.html). Existing structured records do
not become Web tasks; preserve them if you still need the old workflow. Installing
the Web package is not a request to delete or rewrite existing `.agent-bus/` data.

迁移无需先删除旧任务。Web 任务与结构化 Task/Graph 分开存储，保留旧数据后按新版入口
创建 Web 任务即可；不要把 Web 的回执视为旧版 Task 审查或发布授权。

For release details, see [v3 distribution evidence / 分发变更说明](./releases/v3-web-first.md)
and [Changelog / 版本记录](https://hogancv.github.io/coordinate-agents/changelog.html).
