# Install with AI

The canonical machine-readable and bilingual installation procedure is [`AI_INSTALL.md`](https://github.com/hogancv/coordinate-cli-agents/blob/main/AI_INSTALL.md).

Give your AI assistant this request:

```text
Install coordinate-cli-agents from the official repository https://github.com/hogancv/coordinate-cli-agents. Read AI_INSTALL.md first, verify the GitHub owner and npm package, install both CLI skills, and run doctor. Do not request credentials, use a fork or unknown script, modify product code, or start a collaboration task.
```

An installation is complete only when `doctor` succeeds for the selected CLI. The installer writes only to the selected Codex or Antigravity skill home and backs up recognized managed installations before update.
