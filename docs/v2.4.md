# v2.4 docs and v3 migration {#v2-4-docs-and-v3-migration-旧版文档与迁移}

**v2.4 users can continue using the structured workflow.** Starting with v3,
the npm product focuses on the local Web Workspace. The Plugin, Legacy CLI,
MCP, and Task Graph source remain available through separate entry points.
Use the version-specific entry points below; do not replace old command versions with `latest`.

<div id="what-changed--方向变化" class="doc-anchor" aria-hidden="true"></div>
<div id="方向变化" class="doc-anchor" aria-hidden="true"></div>

## What changed {#what-changed-方向变化}

| Area | v2.4.0 | v3 Web-first |
| --- | --- | --- |
| Product entry | Web and structured Plugin / CLI / MCP workflows documented together. | Web Workspace is the main product entry. |
| npm distribution | Complete standalone runtime, including structured commands. | Web/help/version only, with required terminal/runtime modules. |
| Structured workflow | Agent Bus, durable Tasks, review evidence, MCP, Task Graphs. | Retained in the independently versioned GitHub Plugin and source Legacy runtime; npm CLI pins 2.4.0. |
| Web cooperation | Lightweight Web terminal collaboration already existed. | Continues as the main experience; new features depend on the selected source/release. |
| Task data | Structured Task/Graph and Web task records are separate. | No automatic conversion of structured Tasks into Web tasks. |

This is a product and distribution change, not removal of the structured source.
Plugin and npm Web version numbers are independent. Verified on **2026-10-21**:
npm `latest` and the source package are **3.0.2**; the `.codex-plugin` Plugin is **2.4.0**.
This page does not declare an end-of-support date for v2.4 or promise future updates.
v2.4 already had Web mode; v3 did not introduce Web from scratch.

## Continue with v2.4 or move to Web {#continue-with-v2-4-or-move-to-web-继续旧流程或使用新版}

For the published structured CLI, keep the version explicit:

```sh
npx @hogancv/coordinate-agents@2.4.0 --help
npx @hogancv/coordinate-agents@2.4.0 doctor
```

The GitHub Plugin uses its own bundled runtime. From a current source checkout,
use `node bin/coordinate-agents-legacy.mjs` for structured commands. Current
source may include fixes beyond the historical release.

To use Web, follow [Getting started](./getting-started.html) and
[Workspace guide](./inspector.html). Existing structured records do
not become Web tasks; preserve them if you still need the old workflow. Installing
the Web package is not a request to delete or rewrite existing `.agent-bus/` data.
Migration does not require deleting old tasks. Web tasks and structured Task/Graph
records have separate storage; preserve the old data and create Web tasks through
the current entry point. Web receipts do not constitute structured Task review or release approval.

For release details, see [v3 distribution evidence (English)](./releases/v3-web-first.md)
and [Changelog](./changelog.html).
