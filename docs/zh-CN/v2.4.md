# v2.4 文档与 v3 迁移

**v2.4 用户可以继续使用结构化工作流。** 从 v3 开始，npm 产品聚焦本地 Web Workspace。
Plugin、Legacy CLI、MCP 和 Task Graph 源码仍通过独立入口提供。
项目从同时提供 Web 与结构化协作的完整运行时，转向以本地 Web 双终端工作台为主要产品入口。
请根据下方版本入口选择命令，不要直接把旧命令中的版本换成 `latest`。

<div id="what-changed-方向变化" class="doc-anchor" aria-hidden="true"></div>

## 方向变化

| 项目 | v2.4.0 | v3 Web 优先 |
| --- | --- | --- |
| 产品入口 | Web 与结构化 Plugin / CLI / MCP 工作流并列说明。 | Web Workspace 是主要产品入口。 |
| npm 分发 | 包含结构化命令的完整独立运行时。 | 仅提供 Web/help/version 及必要终端与运行时模块。 |
| 结构化能力 | Agent Bus、持久化 Task、审查证据、MCP、Task Graph。 | 通过独立版本的 GitHub Plugin、源码 Legacy 运行时或固定 npm 2.4.0 使用。 |
| Web 协作 | 已有轻量 Web 终端协作。 | 持续作为主要体验；新功能以所选源码或发布版本为准。 |
| 任务数据 | 结构化 Task/Graph 与 Web 任务记录分开。 | 不会把结构化 Task 自动转换为 Web 任务。 |

这是产品重心与分发方式的变化，不代表删除结构化源码。
Plugin 与 npm Web 版本独立。**2026-10-21 已核验**：npm `latest` 与源码包均为 **3.0.2**；
`.codex-plugin` Plugin 为 **2.4.0**。本页不声明 v2.4 的支持终止日期，也不承诺未来更新。
v2.4 已有 Web 模式，v3 并非从零增加 Web。

## 继续旧流程或使用 Web

继续使用已发布的结构化 CLI 时，固定版本：

```sh
npx @hogancv/coordinate-agents@2.4.0 --help
npx @hogancv/coordinate-agents@2.4.0 doctor
```

GitHub Plugin 使用自身内置运行时。在当前源码检出目录中，结构化命令使用
`node bin/coordinate-agents-legacy.mjs`。当前源码可能包含历史发布之后的修复。

使用 Web 请遵循[快速开始](./getting-started.html)和[工作台指南](./inspector.html)。
已有结构化记录不会变成 Web 任务；若还需要旧流程，请保留这些记录。
安装 Web 包不表示用户要求删除或重写现有 `.agent-bus/` 数据。
迁移无需先删除旧任务。Web 任务与结构化 Task/Graph 分开存储；保留旧数据后，
按当前入口创建 Web 任务即可。不要把 Web 回执视为结构化 Task 审查或发布授权。

发布详情见 [v3 分发变更说明（英文）](../releases/v3-web-first.md)和[版本记录](./changelog.html)。
